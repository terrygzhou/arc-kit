# IT4IT Citation Instructions

How to cite the Open Group IT4IT Standard v3.1 (Snapshot) in ArcKit artefacts.

## What S261 Is

S261 is the **Open Group's IT4IT Standard, Version 3.1** — a reference
architecture for IT as product-based investment. It is published as a
**Snapshot**, not an approved standard.

## The Rule: Reference, Never Conformance

- Cite S261 as a **reference architecture**. Artefacts built on it **reference**
  the standard; they never claim **conformance** to it.
- Use phrasing such as:
  - "This artefact references the IT4IT Standard v3.1 (Snapshot, S261)."
  - "S261 is a snapshot, not an approved standard; no conformance claim is made."
- Never write "conforms to S261", "compliant with the IT4IT Standard", or
  similar.
- Vendor refinements, tooling choices, and org-specific customisations are
  **non-normative extensions** of the reference. Record deviations from the S261
  KDO cardinalities as **gaps**, not choices.

## Canonical Citation

For the source line in document control / references:

> The Open Group, *IT4IT Standard, Version 3.1* (Snapshot, S261), 2023.
> Reference only — not a conformance claim.
